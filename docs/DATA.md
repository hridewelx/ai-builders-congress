# Data card — Lotline demo

Everything in this repository's data directory is **synthetic**. No real buyer,
factory, worker or inspection record is used anywhere in the demo.

## What is generated

| Artifact | Path | Generated by | Committed? |
|---|---|---|---|
| Demo database (6 lots, 70 photos, decisions, audit trail) | `data/lotline.db` | `python -m app.seed` | no |
| Evidence images (content-addressed JPEGs) | `data/store/` | `python -m app.seed` | no |
| Detector weights + model card | `data/models/ae_knit_v1.npz`, `model_card.json` | first seed / `vision.save()` | no |
| Staged evaluation dataset | `data/dataset/v1/` | `python scripts/build_dataset.py` | no |

`data/` is git-ignored on purpose: evidence is generated, not shipped, and a
cloned repository must never contain inspection records.

## Build or download

```bash
python scripts/build_dataset.py                # 5 defect classes + clean, ~140 images
python scripts/build_dataset.py --per-class 40 # bigger held-out split
python scripts/build_dataset.py --verify       # re-hash every file against the manifest
python scripts/build_dataset.py --download <url> --sha256 <hex>   # fetch a release archive
```

Generation is deterministic: a seed always produces the same image and the same
normalised truth box. `manifest.json` records the generator, counts, seeds and a
SHA-256 per file, so a downloaded copy can be verified byte-for-byte.

## Dataset shape

```
data/dataset/v1/
  images/train/*.jpg
  images/test/*.jpg
  annotations.jsonl     one JSON record per image: id, split, seed, defects[], label
  manifest.json         counts, class list, annotation hash, per-file hashes
```

Classes: `hole`, `oil_stain`, `needle_line`, `dropped_stitch`, `skipped_stitch`,
plus `clean`. Splits are by seed: every fifth image per class is held out for
evaluation, and no seed appears in both splits.

## Provenance and limits

- **Source:** procedural knit texture (`app/services/vision.py::knit_texture`)
  with injected defects (`_draw_defect`), brightness jitter, slight blur and
  sensor noise.
- **Labels:** the truth box is the region the generator drew — not a human
  annotation. It measures localisation, not agreement between annotators.
- **Limits:** five fabric colours, one camera-like pipeline, no folds, hangers,
  modelled shots, factory lighting, dust or occlusion. Performance on this set
  is **not** evidence of factory performance.
- **Consent:** none required — no people, no real garments, no buyer marks.
- **Licence:** generated by this repository; reuse freely with attribution to
  the project. Do not present it as real inspection data.

## Real-photo addendum (planned, T1.7)

Any real photos added later must be separate from this dataset, carry written
consent, remove faces and buyer labels, and be reported separately in the model
card. The evaluation script must print the two domains apart.
